## 📋 Sobre o Projeto

Este é um currículo online interativo desenvolvido para **Karen Silva dos Reis**, técnica em Desenvolvimento de Sistemas. O site apresenta informações pessoais, habilidades, projetos e contato, com um design sofisticado em **tons de terra, azul marinho e preto**, além de um tema claro/escuro.

### 🎨 Paleta de Cores

| Cor | Nome | Uso |
|---|---|---|
| `#1B2A4A` | Azul Marinho Escuro | Cor primária, botões, cabeçalho |
| `#2C3E6B` | Azul Marinho Médio | Cor secundária, gradientes |
| `#8B6B4D` | Terra Escura | Destaques, bordas, tags |
| `#C4A882` | Terra Clara | Destaque principal, textos |
| `#F5F0EB` | Off-white | Fundo principal |
| `#1A1A1A` | Preto | Fundo escuro, textos |

## ✨ Funcionalidades

- 🔄 **Tema Claro/Escuro** com persistência no LocalStorage
- ⌨️ **Efeito de digitação** automática no cargo
- 🌐 **Integração com GitHub API** para exibir projetos reais
- 📱 **Design responsivo** para todos os dispositivos
- 🎨 **Abstract Linework** com elementos SVG decorativos
- 🔍 **Filtros** para habilidades por categoria
- 📧 **Formulário de contato** com validação
- ⬆️ **Botão "Voltar ao topo"** com animação suave
